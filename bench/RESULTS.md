# Liquid Engine — shop benchmark results

Generated by `bun run bench/shop.bench.ts` (total run 48 s). Numbers are from a single run on the machine below; treat differences under ~10% as noise.

## Environment

- Date: 2026-11-20T16:25:58.095Z
- CPU: Apple M3 Pro, 12 logical cores; OS: darwin 25.5.0
- Bun 1.3.11; SQLite 3.51.0 (bun:sqlite); quickjs-emscripten 0.32.0
- App DB as opened by `openAppDb`: journal_mode=delete, synchronous=2 (defaults; every committed request is a rollback-journal transaction on the DB file)
- Server: `lee serve --handler-dir examples` in a separate process (runner: quickjs); client: `fetch` from the bench process, keep-alive, same machine.
- **LLM generation time was NOT measured**: `ANTHROPIC_API_KEY` is not set and was not used. The JIT-miss rows use the offline generator (reads `examples/<intent>.handler.js`), so they include intent load + dry-run of the `try` inputs on seed copies + live harness, but **zero** model latency. A real miss adds one or more Anthropic API round-trips (seconds) on top.
- Sample sizes: JIT miss n=400 (+20 warm-up); tier latency n=2000 (+200); concurrency 4000 requests/level (+200); data scale n=1000 (+100); in-process n=3000 (+300). Latencies are client-observed wall time via `performance.now()`.
