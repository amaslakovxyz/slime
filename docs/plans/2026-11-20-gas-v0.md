# Liquid Engine v0 — Gas Proof Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the Gas trust level end-to-end: `lee build book_ticket` takes a human-written intent spec, has an agent generate a handler, runs it through the full harness (sandbox → gatekeeper → invariants) against a seeded throwaway DB, always rolls back, and prints an effects diff.

**Architecture:** One shared kernel pipeline — `runThroughHarness()` — is the centerpiece. The Gas build loop and the (future) request path both call it; trust levels differ only in which layers wrap it and whether it may commit. The sandbox sits behind a `Runner` interface so the whole pipeline is built and tested against a plain-function runner first, and QuickJS swaps in last.

**Tech Stack:** Bun + TypeScript, `bun:sqlite`, `quickjs-emscripten` (sync), `@anthropic-ai/sdk`, `bun test`.

## Global Constraints

Copied from `docs/architecture-spec.md`; every task implicitly includes these.

- Single Bun process; the request path never reaches the agent; the build path never touches a real database (v0 has *only* the build path, and it always rolls back).
- Handlers can only read through `db.read` and propose writes through `db.emit`; the kernel decides what commits.
- Handler contract: `export function handler(input, db, ctx) -> { response, error? }` — pure JS, no host I/O.
- `db.read({ table, columns, where, limit })` — `where` is an equality map; the kernel adds `tenant_id`.
- `db.emit({ op: "insert"|"update"|"delete", table, data?, where? })` — collected, never executed by the handler.
- Gatekeeper rules (all required, any failure rejects the complete effect set): role declared in spec; reads/effects target declared tables, operations and columns; `tenant_id` forced on inserts and added to every `where`; updates/deletes address the full primary key by equality; effect count below a fixed cap (**10**); forbidden columns rejected, never silently filtered.
- Invariants: effects applied in the open transaction; invariant `SELECT`s must all return zero rows.
- All tables carry `tenant_id`; money is integer cents.
- Agent repair loop: at most **3** rounds, driven by machine-readable reason codes.

## v0 Scope Decisions

The spec's open questions, resolved for v0 (Tony can revisit in the PR):

| Question | v0 decision |
|---|---|
| `db.read` filters | Equality only — `book_ticket` needs only equality lookups |
| Intents in scope | `book_ticket` only |
| Tenancy | `ctx.tenantId` fixed to `1` in dev; schema keeps `tenant_id` everywhere and the kernel still forces it — that guardrail is part of what we prove |
| Build cache key | **Dropped** (pure optimization); every `lee build` regenerates unless `--handler-file` is passed |
| Deferred entirely | HTTP Dispatcher, Registry/`lee.lock`, fixtures (`accept`/`test`), `freeze`, `LEE_MODE`, `cancel_ticket`, discount rounding policy beyond `Math.round` |

**Offline mode (critical for buildability):** `lee build book_ticket --handler-file <path>` skips the agent and loads handler source from a file. Every task is testable without `ANTHROPIC_API_KEY`. The single live API run at the end is the acceptance test for the whole v0.

## Contracts — the harness layer by layer

All shared types live in `src/types.ts` (Task 1). Each layer consumes and produces only these types; reason codes are the error contract that also feeds the agent repair loop.

```
          Gas build loop (v0)                      request path (later)
          ───────────────────                      ────────────────────
          spec → prompt → agent                    Dispatcher (ctx from session)
                   │                                        │
                   ▼                                        ▼
            handler source                     Registry (pinned hash lookup)
                   │                                        │
                   └────────────┬───────────────────────────┘
                                ▼
               runThroughHarness(runner, spec, source, input, ctx, db, {commit})
                  1. gatekeeper.checkRole(spec, ctx)         → ROLE_NOT_DECLARED
                  2. BEGIN IMMEDIATE
                  3. runner.run(source, input, dbApi, ctx)   → SANDBOX_* / READ_* / HANDLER_ERROR
                  4. gatekeeper.checkEffects(spec, effects)  → WRITE_* / FORBIDDEN_* / PK_* / EFFECT_CAP
                  5. invariants.applyAndCheck(db, effects)   → INVARIANT_VIOLATION
                  6. commit ? COMMIT : ROLLBACK
```

### Trust states × harness layers

v0 builds the **Gas** column; Liquid and Bone *add* layers around the same pipeline — nothing is rewritten.

| Layer | Gas (v0) | Liquid (later) | Bone (later) |
|---|---|---|---|
| Registry pin (`lee.lock`) | — | — | ✓ refuses unpinned code |
| Sandbox (`db.read`/`db.emit` only) | ✓ | ✓ | ✓ |
| Gatekeeper | ✓ | ✓ | ✓ |
| Invariant runner | ✓ | ✓ | ✓ |
| Commit | never — always rollback | dev DB | prod DB |
| Fixture replay (`lee test`) | — | ✓ | ✓ (frozen) |
| Agent reachable | ✓ (build loop only) | ✓ (dev) | module not loaded |

The promotion contracts are defined now, even though v0 implements only Gas, so later iterations extend types instead of inventing them:

```ts
// Liquid: what `lee accept` records and `lee test` replays (spec §Build path step 5)
type Fixture = { intent: string; seed: string; input: unknown; ctxNow: string; effects: Effect[] };
// Bone: what `lee freeze` pins and the Registry refuses to serve without (spec §Trust levels)
type LockEntry = { intent: string; handlerHash: string; specHash: string; frozenAt: string };
```

Promotion/demotion rule (from the spec, restated as the state machine v0's types must not contradict): a spec edit drops the intent to Gas and marks fixtures stale; passing Gatekeeper + invariants + accepted fixtures makes it Liquid; only a human `lee freeze` commit makes it Bone.

### Shared types (authoritative — later tasks must match these exactly)

```ts
// src/types.ts
export type Ctx = { tenantId: number; userId: number; role: string; now: string };

export type ReadQuery = {
  table: string;
  columns: string[];
  where: Record<string, string | number>;
  limit?: number;
};

export type Effect = {
  op: "insert" | "update" | "delete";
  table: string;
  data?: Record<string, unknown>;
  where?: Record<string, string | number>;
};

export type HandlerResult = { response: unknown; error?: string };

export type Reason =
  | "ROLE_NOT_DECLARED"
  | "READ_TABLE_NOT_DECLARED"
  | "READ_COLUMN_UNKNOWN"
  | "WRITE_NOT_DECLARED"      // table+op pair absent from spec.writes
  | "COLUMN_UNKNOWN"          // effect column not in schema
  | "FORBIDDEN_COLUMN"        // kernel-owned column supplied by handler
  | "PK_NOT_FULLY_ADDRESSED"  // update/delete without full-PK equality
  | "EFFECT_CAP_EXCEEDED"
  | "INVARIANT_VIOLATION"
  | "HANDLER_ERROR"           // handler threw or returned {error}
  | "SANDBOX_TIMEOUT"
  | "SANDBOX_MEMORY"
  | "SANDBOX_CRASH"
  | "GENERATION_FAILED";      // agent exhausted 3 rounds

export type GateResult = { ok: true } | { ok: false; reason: Reason; detail: string };

export type HarnessOutcome =
  | { ok: true; response: unknown; effects: Effect[] }
  | { ok: false; stage: "role" | "sandbox" | "gatekeeper" | "invariants"; reason: Reason; detail: string };

export type IntentSpec = {
  name: string;
  roles: string[];
  reads: string[];
  writes: { table: string; ops: Effect["op"][] }[];
  rule: string;                                   // free text, goes into the prompt
  invariants: { name: string; sql: string }[];
  try: Record<string, unknown>[];                 // dry-run inputs
};

// Guardrail violations raised inside db.read are thrown as this tagged error
// so the harness can map them to a Reason instead of a generic HANDLER_ERROR.
export class GuardrailError extends Error {
  constructor(public reason: Reason, public detail: string) { super(`${reason}: ${detail}`); }
}

export const EFFECT_CAP = 10;
export const FORBIDDEN_COLUMNS = ["tenant_id", "id"]; // kernel-owned: tenant forced, id autoincrement
```

```ts
import type { IntentSpec, Effect } from "./types";

const FIELD = /^(roles|reads|writes|rule|try|invariant (\w+)):\s*(.*)$/;

export function parseIntent(markdown: string, name: string): IntentSpec {
  const body = markdown.match(/```([\s\S]*?)```/)?.[1];
  if (!body) throw new Error(`no spec block in intent ${name}`);

  const fields: { key: string; invName?: string; lines: string[] }[] = [];
  for (const raw of body.split("\n")) {
    const m = raw.match(FIELD);
    if (m) fields.push({ key: m[2] ? "invariant" : m[1], invName: m[2], lines: [m[3]] });
    else if (raw.trim() && fields.length) fields.at(-1)!.lines.push(raw.trim());
  }
  const val = (k: string) => fields.find(f => f.key === k)?.lines.join(" ").trim() ?? "";
  const list = (k: string) => val(k).split(",").map(s => s.trim()).filter(Boolean);

  return {
    name,
    roles: list("roles"),
    reads: list("reads"),
    writes: list("writes").map(w => {
      const m = w.match(/^(\w+)\((\w+(?:,\s*\w+)*)\)$/);
      if (!m) throw new Error(`bad writes entry: ${w}`);
      return { table: m[1], ops: m[2].split(",").map(s => s.trim()) as Effect["op"][] };
    }),
    rule: val("rule"),
    invariants: fields.filter(f => f.key === "invariant")
      .map(f => ({ name: f.invName!, sql: f.lines.join(" ") })),
    try: fields.filter(f => f.key === "try")
      .map(f => new Function(`return (${f.lines.join(" ")})`)() as Record<string, unknown>),
  };
}
```

```ts
import { Database } from "bun:sqlite";

export const SCHEMA: Record<string, string[]> = {
  events: ["id", "tenant_id", "capacity", "price_cents"],
  tickets: ["id", "tenant_id", "event_id", "user_id", "qty", "promo_code", "total_cents"],
  promos: ["code", "tenant_id", "pct", "max_uses"],
};
export const PK: Record<string, string> = { events: "id", tickets: "id", promos: "code" };

export const DDL = `
CREATE TABLE events  (id INTEGER PRIMARY KEY, tenant_id INTEGER NOT NULL, capacity INTEGER NOT NULL, price_cents INTEGER NOT NULL);
CREATE TABLE tickets (id INTEGER PRIMARY KEY AUTOINCREMENT, tenant_id INTEGER NOT NULL, event_id INTEGER NOT NULL, user_id INTEGER NOT NULL, qty INTEGER NOT NULL, promo_code TEXT, total_cents INTEGER NOT NULL);
CREATE TABLE promos  (code TEXT PRIMARY KEY, tenant_id INTEGER NOT NULL, pct INTEGER NOT NULL, max_uses INTEGER NOT NULL);
`;

const SEED = `
INSERT INTO events VALUES (7, 1, 100, 5000), (8, 1, 2, 10000);
INSERT INTO promos VALUES ('FALL10', 1, 10, 100), ('BIG90', 1, 90, 100);
`;

export function createSeedDb(): Database {
  const db = new Database(":memory:");
  db.exec(DDL);
  db.exec(SEED);
  return db;
}
```

```ts
import type { Database } from "bun:sqlite";
import { SCHEMA } from "./db";
import { GuardrailError, type Ctx, type Effect, type IntentSpec, type ReadQuery } from "./types";
import type { DbApi } from "./runner";

export function makeDbApi(db: Database, spec: IntentSpec, ctx: Ctx) {
  const collected: Effect[] = [];

  const api: DbApi = {
    read(q: ReadQuery) {
      const cols = SCHEMA[q.table];
      if (!cols || !spec.reads.includes(q.table))
        throw new GuardrailError("READ_TABLE_NOT_DECLARED", `read from '${q.table}'`);
      for (const c of [...q.columns, ...Object.keys(q.where)])
        if (!cols.includes(c))
          throw new GuardrailError("READ_COLUMN_UNKNOWN", `'${c}' on '${q.table}'`);

      const where = { ...q.where, tenant_id: ctx.tenantId }; // kernel adds tenant filter
      const keys = Object.keys(where);
      const sql = `SELECT ${q.columns.join(", ")} FROM ${q.table}
                   WHERE ${keys.map(k => `${k} = ?`).join(" AND ")}
                   LIMIT ${Math.min(q.limit ?? 100, 100)}`;
      return db.query(sql).all(...keys.map(k => where[k])) as Record<string, unknown>[];
    },
    emit(e: Effect) {
      collected.push(e); // validation is the Gatekeeper's job, after the handler finishes
    },
  };
  return { api, effects: () => [...collected] };
}
```

(Interpolating `q.table`/columns into SQL is safe only because both were just validated against the `SCHEMA` allowlist — values still go through placeholders.)

```ts
  test("declared insert passes", () => expect(checkEffects(spec, [good]).ok).toBe(true));
  test("undeclared table → WRITE_NOT_DECLARED", () =>

    expect(checkEffects(spec, [{ op: "delete", table: "tickets", where: { id: 1 } }])).toMatchObject({ ok: false, reason: "WRITE_NOT_DECLARED" }));

    expect(checkEffects(spec, [ins({ ...good.data, hacked: 1 })])).toMatchObject({ ok: false, reason: "COLUMN_UNKNOWN" }));
  test("handler-supplied tenant_id → FORBIDDEN_COLUMN, not filtered", () =>
    expect(checkEffects(spec, [ins({ ...good.data, tenant_id: 2 })])).toMatchObject({ ok: false, reason: "FORBIDDEN_COLUMN" }));

    expect(checkEffects(spec, Array.from({ length: EFFECT_CAP + 1 }, () => good)))
```

```ts
import { PK, SCHEMA } from "./db";
import { EFFECT_CAP, FORBIDDEN_COLUMNS, type Ctx, type Effect, type GateResult, type IntentSpec, type Reason } from "./types";

const fail = (reason: Reason, detail: string): GateResult => ({ ok: false, reason, detail });

export function checkRole(spec: IntentSpec, ctx: Ctx): GateResult {
  return spec.roles.includes(ctx.role) ? { ok: true }
    : fail("ROLE_NOT_DECLARED", `role '${ctx.role}' not in [${spec.roles}]`);
}

export function checkEffects(spec: IntentSpec, effects: Effect[]): GateResult {
  if (effects.length > EFFECT_CAP)
    return fail("EFFECT_CAP_EXCEEDED", `${effects.length} > ${EFFECT_CAP}`);

  for (const e of effects) {
    const declared = spec.writes.find(w => w.table === e.table);
    if (!declared || !declared.ops.includes(e.op))
      return fail("WRITE_NOT_DECLARED", `${e.op} on '${e.table}'`);

    const cols = SCHEMA[e.table];
    for (const c of Object.keys(e.data ?? {})) {
      if (FORBIDDEN_COLUMNS.includes(c))
        return fail("FORBIDDEN_COLUMN", `'${c}' is kernel-owned`); // rejected, never filtered
      if (!cols.includes(c)) return fail("COLUMN_UNKNOWN", `'${c}' on '${e.table}'`);
    }
    for (const c of Object.keys(e.where ?? {})) {
      if (c === "tenant_id") return fail("FORBIDDEN_COLUMN", `'tenant_id' in where is kernel-owned`);
      if (!cols.includes(c)) return fail("COLUMN_UNKNOWN", `'${c}' on '${e.table}'`);
    }
    if ((e.op === "update" || e.op === "delete") && !(PK[e.table] in (e.where ?? {})))
      return fail("PK_NOT_FULLY_ADDRESSED", `${e.op} on '${e.table}' must address ${PK[e.table]} by equality`);
  }
  return { ok: true };
}
```

```ts
import type { Database } from "bun:sqlite";
import type { Ctx, Effect, GateResult, IntentSpec } from "./types";

// Caller holds the open transaction; this never commits or rolls back.
// Must only ever run on a gate-passed effect set (runThroughHarness enforces the order),
// so table/column names here are already allowlist-validated.
export function applyAndCheck(db: Database, spec: IntentSpec, effects: Effect[], ctx: Ctx): GateResult {
  for (const e of effects) {
    if (e.op === "insert") {
      const data = { ...e.data, tenant_id: ctx.tenantId }; // kernel forces tenant
      const keys = Object.keys(data);
      db.query(`INSERT INTO ${e.table} (${keys.join(",")}) VALUES (${keys.map(() => "?").join(",")})`)
        .run(...keys.map(k => (data as any)[k]));
    } else {
      const where = { ...e.where, tenant_id: ctx.tenantId }; // kernel adds tenant to every where
      const wk = Object.keys(where);
      if (e.op === "update") {
        const dk = Object.keys(e.data ?? {});
        db.query(`UPDATE ${e.table} SET ${dk.map(k => `${k} = ?`).join(", ")}
                  WHERE ${wk.map(k => `${k} = ?`).join(" AND ")}`)
          .run(...dk.map(k => (e.data as any)[k]), ...wk.map(k => (where as any)[k]));
      } else {
        db.query(`DELETE FROM ${e.table} WHERE ${wk.map(k => `${k} = ?`).join(" AND ")}`)
          .run(...wk.map(k => (where as any)[k]));
      }
    }
  }
  for (const inv of spec.invariants) {
    const rows = db.query(inv.sql).all();
    if (rows.length > 0)
      return { ok: false, reason: "INVARIANT_VIOLATION", detail: `invariant '${inv.name}' returned ${rows.length} row(s)` };
  }
  return { ok: true };
}
```

```ts
import type { Database } from "bun:sqlite";
import { makeDbApi } from "./dbapi";
import { checkEffects, checkRole } from "./gatekeeper";
import { applyAndCheck } from "./invariants";
import type { Runner } from "./runner";
import { GuardrailError, type Ctx, type HarnessOutcome, type IntentSpec } from "./types";

export function runThroughHarness(
  runner: Runner, spec: IntentSpec, source: string, input: unknown,
  ctx: Ctx, db: Database, opts: { commit: boolean },
): HarnessOutcome {
  const role = checkRole(spec, ctx);
  if (!role.ok) return { ok: false, stage: "role", reason: role.reason, detail: role.detail };

  db.exec("BEGIN IMMEDIATE");
  try {
    const { api, effects } = makeDbApi(db, spec, ctx);

    let result;
    try {
      result = runner.run(source, input, api, ctx);
    } catch (err) {
      if (err instanceof GuardrailError)
        return rollback(db, { ok: false, stage: "sandbox", reason: err.reason, detail: err.detail });
      return rollback(db, { ok: false, stage: "sandbox", reason: "HANDLER_ERROR", detail: String(err) });
    }
    if (result.error)
      return rollback(db, { ok: false, stage: "sandbox", reason: "HANDLER_ERROR", detail: result.error });

    const gate = checkEffects(spec, effects());
    if (!gate.ok) return rollback(db, { ok: false, stage: "gatekeeper", reason: gate.reason, detail: gate.detail });

    const inv = applyAndCheck(db, spec, effects(), ctx);
    if (!inv.ok) return rollback(db, { ok: false, stage: "invariants", reason: inv.reason, detail: inv.detail });

    if (opts.commit) db.exec("COMMIT");
    else db.exec("ROLLBACK"); // Gas never commits
    return { ok: true, response: result.response, effects: effects() };
  } catch (err) {
    return rollback(db, { ok: false, stage: "sandbox", reason: "SANDBOX_CRASH", detail: String(err) });
  }
}

function rollback(db: Database, out: HarnessOutcome): HarnessOutcome {
  try { db.exec("ROLLBACK"); } catch {}
  return out;
}
```

```ts
import { getQuickJS } from "quickjs-emscripten";
import { GuardrailError, type Ctx, type HandlerResult } from "./types";
import type { DbApi, Runner } from "./runner";

export async function createQuickJsRunner(
  opts: { memoryLimitBytes?: number; deadlineMs?: number } = {},
): Promise<Runner> {
  const QuickJS = await getQuickJS(); // sync variant: host functions may be called re-entrantly
  const { memoryLimitBytes = 32 * 1024 * 1024, deadlineMs = 500 } = opts;

  return {
    run(source: string, input: unknown, db: DbApi, ctx: Ctx): HandlerResult {
      const runtime = QuickJS.newRuntime();
      let hostError: unknown; // GuardrailErrors must cross the VM boundary intact
      try {
        runtime.setMemoryLimit(memoryLimitBytes);
        const deadline = Date.now() + deadlineMs;
        runtime.setInterruptHandler(() => Date.now() > deadline);
        const vm = runtime.newContext();
        try {
          const host = (name: string, impl: (json: string) => string) => {
            const fn = vm.newFunction(name, argH => {
              try { return vm.newString(impl(vm.getString(argH))); }
              catch (e) { hostError = e; throw e; } // surfaces inside the VM as an exception too
            });
            vm.setProp(vm.global, name, fn);
            fn.dispose();
          };
          host("__read", json => JSON.stringify(db.read(JSON.parse(json))));
          host("__emit", json => (db.emit(JSON.parse(json)), "null"));

          const body = source.replace(/^\s*export\s+/m, "");
          const program = `
            const ctx = ${JSON.stringify(ctx)};
            const db = {
              read: q => JSON.parse(__read(JSON.stringify(q))),
              emit: e => { __emit(JSON.stringify(e)); },
            };
            ${body}
            JSON.stringify(handler(${JSON.stringify(input)}, db, ctx))
          `;
          const result = vm.evalCode(program);
          if (result.error) {
            const detail = JSON.stringify(vm.dump(result.error));
            result.error.dispose();
            if (hostError instanceof GuardrailError) throw hostError;
            if (Date.now() > deadline) throw new GuardrailError("SANDBOX_TIMEOUT", `exceeded ${deadlineMs}ms`);
            if (/out of memory/i.test(detail)) throw new GuardrailError("SANDBOX_MEMORY", detail);
            throw new GuardrailError("HANDLER_ERROR", detail);
          }
          const json = vm.getString(result.value);
          result.value.dispose();
          return JSON.parse(json) as HandlerResult;
        } finally {
          vm.dispose();
        }
      } finally {
        runtime.dispose();
      }
    },
  };
}
```

```ts
import Anthropic from "@anthropic-ai/sdk";
import { createSeedDb, DDL } from "./db";
import { runThroughHarness } from "./harness";
import type { Runner } from "./runner";
import type { Ctx, IntentSpec } from "./types";

const DEV_CTX: Ctx = { tenantId: 1, userId: 42, role: "user", now: "2026-11-20T12:00:00Z" };

export function buildPrompt(spec: IntentSpec, priorFailure?: { reason: string; detail: string }): string {
  return [
    "Write a JavaScript handler for this business intent. Return ONLY the code, no prose, no markdown fence.",
    "",
    "Contract:",
    "  export function handler(input, db, ctx) -> { response, error? }",
    "  db.read({ table, columns, where, limit }) -> rows   // where: equality map only; tenant filtering is automatic",
    "  db.emit({ op: 'insert'|'update'|'delete', table, data?, where? })  // propose a write; never applied directly",
    "  ctx = { tenantId, userId, role, now }",
    "  Never set tenant_id or id yourself — the kernel owns them and will reject the write.",
    "  No imports, no fetch, no fs, no Date.now — pure logic over db.read/db.emit only.",
    "",
    `Intent: ${spec.name}`,
    `Rule: ${spec.rule}`,
    `Allowed reads: ${spec.reads.join(", ")}`,
    `Allowed writes: ${spec.writes.map(w => `${w.table}(${w.ops.join(",")})`).join(", ")}`,
    ...spec.invariants.map(i => `Invariant '${i.name}' (your writes must not make this SELECT return rows): ${i.sql}`),
    "",
    "Schema:", DDL,
    ...(priorFailure
      ? ["", `Your previous attempt was REJECTED by the harness: ${priorFailure.reason} — ${priorFailure.detail}`, "Fix exactly that and return the full corrected handler."]
      : []),
  ].join("\n");
}

export async function generateWithRepair(
  generate: (prompt: string) => Promise<string>,
  spec: IntentSpec, runner: Runner, maxRounds = 3,
): Promise<{ ok: true; source: string } | { ok: false; reason: "GENERATION_FAILED"; detail: string }> {
  let failure: { reason: string; detail: string } | undefined;
  for (let round = 1; round <= maxRounds; round++) {
    const source = await generate(buildPrompt(spec, failure));
    // every try input must pass the full harness, each on a fresh seed copy, never committing
    failure = undefined;
    for (const input of spec.try) {
      const out = runThroughHarness(runner, spec, source, input, DEV_CTX, createSeedDb(), { commit: false });
      if (!out.ok) { failure = { reason: out.reason, detail: out.detail }; break; }
    }
    if (!failure) return { ok: true, source };
  }
  return { ok: false, reason: "GENERATION_FAILED", detail: `${maxRounds} rounds exhausted; last: ${failure!.reason} — ${failure!.detail}` };
}

export async function anthropicGenerate(prompt: string): Promise<string> {
  const client = new Anthropic(); // reads ANTHROPIC_API_KEY from env
  const msg = await client.messages.create({
    model: "claude-sonnet-5", max_tokens: 2048,
    messages: [{ role: "user", content: prompt }],
  });
  const text = msg.content.filter(b => b.type === "text").map(b => b.text).join("");
  return text.replace(/^```(?:js|javascript)?\n?/, "").replace(/\n?```\s*$/, ""); // belt & braces
}
```

```ts
import { anthropicGenerate, generateWithRepair } from "./agent";
import { createSeedDb } from "./db";
import { runThroughHarness } from "./harness";
import { FnRunner, type Runner } from "./runner";
import { parseIntent } from "./spec";
import type { Ctx } from "./types";

const DEV_CTX: Ctx = { tenantId: 1, userId: 42, role: "user", now: new Date().toISOString() };

async function main() {
  const [cmd, intent, ...rest] = Bun.argv.slice(2);
  if (cmd !== "build" || !intent) die("usage: lee build <intent> [--handler-file <path>]");

  const specFile = Bun.file(`intents/${intent}.md`);
  if (!(await specFile.exists())) die(`unknown intent '${intent}' (no intents/${intent}.md)`);
  const spec = parseIntent(await specFile.text(), intent);

  let runner: Runner;
  let runnerName = "quickjs";
  try {
    const { createQuickJsRunner } = await import("./quickjs-runner");
    runner = await createQuickJsRunner();
  } catch {
    console.warn("! quickjs unavailable, falling back to FnRunner (NO isolation)");
    runner = new FnRunner();
    runnerName = "fn (NO isolation)";
  }

  const fileIdx = rest.indexOf("--handler-file");
  let source: string;
  if (fileIdx >= 0) {
    source = await Bun.file(rest[fileIdx + 1]).text();
  } else {
    const gen = await generateWithRepair(anthropicGenerate, spec, runner);
    if (!gen.ok) die(`GAS FAIL ${gen.reason}: ${gen.detail}`);
    source = gen.source;
  }

  const hash = new Bun.CryptoHasher("sha256").update(source).digest("hex").slice(0, 12);
  console.log(`intent: ${intent}  handler: ${hash}  runner: ${runnerName}  (gas — nothing committed)\n`);

  let failed = false;
  for (const input of spec.try) {
    const out = runThroughHarness(runner, spec, source, input, DEV_CTX, createSeedDb(), { commit: false });
    console.log(`try ${JSON.stringify(input)}`);
    if (out.ok) {
      console.log(`  response: ${JSON.stringify(out.response)}`);
      console.log(`  effects (proposed, rolled back):\n${JSON.stringify(out.effects, null, 2).replace(/^/gm, "    ")}`);
    } else {
      failed = true;
      console.log(`  REJECTED at ${out.stage}: ${out.reason} — ${out.detail}`);
    }
  }
  console.log(failed ? "\nGAS FAIL" : "\nGAS PASS — all try inputs survived the harness; db rolled back");
  process.exit(failed ? 1 : 0);
}

function die(msg: string): never { console.error(msg); process.exit(1); }
await main();
```

## What v0 proves / what it defers

**Proves:** the core guardrail story — agent-generated code runs with zero host access, can only read through a tenant-filtered allowlist and propose writes that must survive an explicit gatekeeper and SQL invariants inside a transaction that never commits; rejection reasons are machine-readable and drive the agent's repair loop.

**Defers (in promotion order):** fixtures + `lee accept`/`lee test` (Liquid), Dispatcher + Registry + `lee.lock` + `lee freeze` (Bone), build cache key, `LEE_MODE`, additional intents, non-equality read filters.
